XRay AntiCheat — Third-Party Notices
=====================================================================================

This project is proprietary (see LICENSE.txt). It depends upon third-party components
that remain governed by their own licenses. This file lists them so the obligations are
visible without unpacking a jar.

THE SHORT VERSION: the plugin jar contains only this project's own code and its
configuration files. It redistributes nothing. Every third-party library it needs is
either already provided by the server or fetched by the server from Maven Central at
runtime, under the name and version declared in plugin.yml. That distinction matters for
licensing, and it is the reason the LGPL section at the bottom is no longer the problem it
once was.

Consequences of that design, stated plainly:

  * There is no third-party code in the jar to carry notices for. Verified: the packaged
    jar contains zero entries under org/sqlite, org/postgresql, org/mariadb, com/zaxxer
    or org/slf4j. tools/ci/verify_jar.sh fails the build if that changes.
  * No build-time notice transformer is needed, because there is nothing to merge.
  * You are still *depending* on these libraries, and on the servers they are downloaded
    to. This file is the authoritative list of what and under which licence.

LGPL NOTE — IMPROVED BY THE RUNTIME-LIBRARIES DESIGN
-------------------------------------------------------------------------------------

The MariaDB Connector/J is LGPL-2.1, a copyleft licence with real obligations on
redistribution, including requirements about the recipient's ability to substitute a
modified version of the library.

Previously this driver was bundled inside the shaded jar, which made those obligations
directly applicable to anyone distributing the plugin. It is no longer redistributed
here: the jar contains none of it, and the server fetches the library from Maven Central
under its original name and version. The recipient gets the library from its publisher,
not from this project.

That removes the redistribution question for this plugin. It does not remove the licence
altogether — the plugin still depends on the library and users still run code under
LGPL-2.1 — but the obligations now sit with the library's publisher and the server
operator rather than with the distributor of this plugin.

If you change the build so that any of these libraries is bundled again, this section
becomes inaccurate and the obligations revert to you. tools/ci/verify_jar.sh exists partly
to stop that happening by accident.

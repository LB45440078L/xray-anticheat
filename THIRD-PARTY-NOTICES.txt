This project is proprietary (see LICENSE.txt). It bundles and depends upon third-party

THIS FILE IS THE AUTHORITATIVE LIST. The shaded jar does NOT carry the complete set of
notices, and cannot: it can only reproduce the license files its dependencies actually
ship. Verified against the real dependency jars, the position is:

  carried inside the shaded jar  : PostgreSQL JDBC Driver (META-INF/LICENSE), and
                                   sqlite-jdbc (two notices under
                                   META-INF/maven/org.xerial/sqlite-jdbc/), plus the
                                   nested licence files the PostgreSQL driver itself
                                   bundles for its SCRAM/stringprep dependencies under
                                   META-INF/licenses/.

A build-time transformer merges the notice files that do exist, so that one is not
silently discarded in favour of another. It cannot invent the missing ones. If you
redistribute the JAR, supply the texts below yourself.

RUNTIME COMPONENTS BUNDLED INTO THE SHADED JAR
-------------------------------------------------------------------------------------

  HikariCP
    JDBC connection pool.
    License: Apache License 2.0
    Relocated to io.xrayac.libs.hikari in the shaded jar.

  sqlite-jdbc (org.xerial)
    SQLite JDBC driver, including its bundled native libraries.
    License: Apache License 2.0
    DELIBERATELY NOT relocated: it is a JNI library whose native symbol names are derived
    from the original class names, so relocating it breaks the driver at runtime.

  SLF4J API (org.slf4j)
    Logging facade.
    License: MIT License

  PostgreSQL JDBC Driver (org.postgresql)
    PostgreSQL connectivity.
    License: BSD 2-Clause License

  MariaDB Connector/J (org.mariadb.jdbc)
    MariaDB / MySQL connectivity.
    License: GNU Lesser General Public License 2.1

  SCRAM and stringprep libraries (com.ongres.scram, com.ongres.stringprep)
    Transitive dependencies of the PostgreSQL driver's SCRAM authentication support.
    License: Apache License 2.0
